1. Autenticação

Fazer login e obter token JWT

GET /auth/me Protegido

Ver dados do usuário logado

2. Bolos

GET /bolos

Listar todos os bolos

GET /bolos/:id

Buscar bolo por ID

POST /bolos Admin

Criar novo bolo

3. Carrinho

GET /carrinho Protegido

Ver carrinho do usuário

POST /carrinho/adicionar Protegido

Adicionar item ao carrinho

DELETE /carrinho/limpar Protegido

Limpar carrinho

4. Pedidos

POST /pedidos/criar Protegido

Criar pedido do carrinho

GET /pedidos Protegido

Listar pedidos do usuário

GET /pedidos/:id/whatsapp Protegido

Gerar mensagem WhatsApp
