# Frontend - Documentacao

Documentacao do frontend da A&L Cakes.

## Stack

- HTML5, CSS3, JavaScript ES6+
- jQuery 3.7.1 (DOM e AJAX)
- SweetAlert2 (modais de confirmacao)
- Chart.js (graficos do dashboard)
- Font Awesome 6 (icones)

## Estrutura da doc

- **estrutura.md** - Organizacao de pastas e responsabilidades de cada arquivo
- **paginas.md** - Funcionalidade e fluxo de cada pagina
- **componentes.md** - Componentes reutilizaveis e seus comportamentos
- **execucao.md** - Setup local e variaveis de ambiente

## Leitura recomendada

1. `estrutura.md` - Visao geral da codebase
2. `execucao.md` - Como subir o ambiente
3. `paginas.md` - Fluxo das telas
4. `componentes.md` - Componentes compartilhados
